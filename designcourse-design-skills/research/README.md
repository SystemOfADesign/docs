# Research: per-video extractions

One directory per source video, named by YouTube video id. Each holds `extraction.md`: source metadata, an access record, timestamped paraphrased findings, concrete guidance with before and after observations, a key-frame table, practical rules, and limitations. They are original notes, not transcripts, and are not affiliated with or endorsed by the creator.

## Frame stills (`assets/`)

Each extraction links to up to eight downscaled stills under `assets/`. They are frames from the videos, some showing third-party designs, kept as analysis references. In the published copy of this package they are omitted, so those links are dead there; the key-frame tables describe what each still shows. In the local working copy the files are present.
