# Fact-check: Theo's technical and economic claims

**One line:** the direction of the thesis holds (isolates are far cheaper than reserved VMs, Rust beats Go for WASM, TS 7.0 dropped the JS API), but the systems explanation is wrong in several places (isolates "in the kernel", Docker running OSes), several numbers are off (Cursor VM size, Go WASM floor, the "8x per month" maths), and "nothing comparable exists" ignores Cloudflare's own August 2026 release.

Scope: [19:54-41:30], plus Go/GC/WASM claims at [10:40-13:15] and [21:25-22:55]. Claims are paraphrased. Checked 2026-11-25; web fetch and search worked.

Verdict scale: **accurate** / **roughly right** / **loose wording** / **wrong** / **unverifiable**.

Source labels in the "what is true" column: VERIFIED = primary source at the URL; INFERRED = my reasoning from verified facts; FROM MEMORY = not checked.

## Net assessment

### Holds up

- **Isolates are an order of magnitude or two lighter than containers or VMs.** Cloudflare's figures: ~5 ms and ~3 MB vs hundreds of ms and hundreds of MB. Vendor numbers, but consistent across 2018 and 2026 posts.
- **Billing model matters as much as weight.** Workers bill CPU time, not wall time. An agent that waits 114 s on a model and computes for 0.2 s is the ideal case.
- **The gap is large for long, idle, big-memory sessions.** A 16-32 GB VM held for 8 hours is ~$2.70-$5.40 at Vercel's memory rate; a never-hibernating Durable Object is ~$0.045 (INFERRED from verified rates).
- **Go-to-WASM is a bad fit; Rust-to-WASM can be a good one.** 49 MB (unofficial tsgo-wasm) vs 4.2 MB (ts-rust-wasm). Go does not use WasmGC and has no plan to.
- **TypeScript 7.0 dropped the JS API**, and Microsoft has not announced an official WASM/browser build. A checker that runs in an isolate was a real missing piece.
- **Vercel Sandbox shares infrastructure with Vercel hosting; Cloudflare's container sandbox does not share it with Workers.** Both confirmed by the vendors' own text.
- **Inference prices at fixed capability fall 10x+ per year.** Independent source agrees on the range.

### Oversold or wrong

- **The systems explanation.** Isolates are not "in the kernel"; Docker does not run an OS or a kernel shim per container; you cannot mix Windows and Linux tenants in Docker on one kernel; Chrome's site boundary is processes, not isolates. The conclusion (isolates are lighter) survives; the reasoning given does not.
- **"There isn't anything comparable."** WebContainers (2021), Bolt, and above all `@cloudflare/computer` (August 2026: just-bash in a Dynamic Worker, container only when needed) are the same idea. The demo's new contribution is narrower: in-isolate TS 7 typechecking.
- **"The VM will soon cost more than the inference."** Not at public prices today: small sandboxes are ~$0.17/hour and bill active CPU only. The 25-30% per year VM inflation figure has no source; 2026 was a one-off memory shock.
- **The evidence that free VMs are ending.** Cursor's VM is 16 GB, not 32, and still free. Claude Code's "credit" was a promotion; its docs say the VM has no separate charge.
- **"It costs nothing" on a Worker.** Stateful agents need Durable Objects (wall-clock billed) and Dynamic Workers ($0.002 per unique worker per day). For a 2-minute session the per-build Dynamic Worker fee can exceed a microVM's cost.
- **"Could run entirely in a Cloudflare Worker."** Untested at recording time. The demo's toy app would use ~100 MB of the 128 MB an isolate allows if agent and checker shared one isolate (24 MB heap + 75 MB WASM peak, INFERRED), and it needs a redesign around the lack of threads.
- **Scale.** The demo typechecks two files. Nothing shown supports real repositories inside 128 MB and one thread.
- **Security is not discussed.** just-bash says "without VM isolation"; `node:vm` is "not a security mechanism". Running model-written code in the agent's own isolate is the easy path and the unsafe one.
- **Numbers said vs shown.** "Under 216 megs" vs 259 MB on screen; "8x per month" vs ~1.56x per month from his own figures.

### Bottom line

- The idea is sound and already being productized (by Cloudflare) as a **hybrid**: isolate first, container when a real binary is needed.
- Theo's genuine addition is a small WASM build of a TS 7-compatible checker, which closes one of the biggest holes in the isolate-only path.
- Treat the cost story as "10-100x cheaper compute for sessions that fit", not "free", and not yet "the VM costs more than the model".
